\section{Learning Outcomes}

\begin{frame}{Learning Outcomes}
    By the end of this session, you should be able to:
    \vspace{0.4em}
    \begin{itemize}\itemsep0.4em
        \item \textbf{Derive} linear attention as a recurrence, and explain how gating and the delta rule turn it into the mixers used in 2026 hybrids.
        \item \textbf{Compare} state-space models, RWKV, xLSTM and Hyena against a Transformer baseline on recall, throughput and scale.
        \item \textbf{Analyse} Mixture-of-Experts routing, load balancing and serving cost at frontier scale.
        \item \textbf{Explain} how FlashAttention-3 and 4, sliding windows and learned sparse attention cut the cost of attention.
        \item \textbf{Evaluate} long-context methods and tell a claimed context window from an effective one.
        \item \textbf{Apply} scaling laws to a training budget, and state where they stop holding.
        \item \textbf{Describe} the current design choices in natively multimodal models.
    \end{itemize}
\end{frame}
