\section{Learning Outcomes}

\begin{frame}{Learning Outcomes}
    By the end of this session, you should be able to:
    \vspace{0.4em}
    \begin{itemize}\itemsep0.4em
        \item \textbf{Place} IPO, SimPO, ORPO, KTO and the GRPO family on one map, and name the failure each variant fixes.
        \item \textbf{Explain} why frontier recipes moved from offline preferences to on-policy RL with verifiable rewards.
        \item \textbf{Design} a reward for RL post-training, and predict how it will be over-optimised or hacked.
        \item \textbf{Compare} scalable-oversight protocols: debate, weak-to-strong generalisation, critics and specifications.
        \item \textbf{Build} a synthetic data pipeline with the right quality controls, and state when it collapses.
        \item \textbf{Analyse} self-improvement loops: what bounds them and how their evaluations mislead.
        \item \textbf{Plan} continual updates, merging and an open-source post-training run end to end.
    \end{itemize}
\end{frame}
