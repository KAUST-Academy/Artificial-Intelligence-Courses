\section{Learning Outcomes}

\begin{frame}{Learning Outcomes}
    By the end of this session, you should be able to:
    \vspace{0.2em}
    \begin{itemize}\itemsep0.05em
        \item \textbf{Explain} how agents moved from plan-first scaffolds to RL-trained agentic models.
        \item \textbf{Analyse} tool use: schema, selection, arguments, execution feedback and recovery.
        \item \textbf{Describe} the 2026 Model Context Protocol, its trust boundaries and its attacks.
        \item \textbf{Compare} memory architectures by memory type, write policy and retrieval structure.
        \item \textbf{Decide} when a multi-agent system pays for its coordination cost.
        \item \textbf{Evaluate} when a world model or a synthetic environment helps an agent.
        \item \textbf{Report} an agent benchmark score with the conditions that give it meaning.
        \item \textbf{Design} the operational layer: identity, approval, audit trails and cost controls.
    \end{itemize}
    \vspace{0.3em}
    {\footnotesize \textbf{Prerequisite knowledge:} the ReAct loop and function calling; MCP roles and primitives; RAG, GraphRAG, HippoRAG and Self-Route; tree search with RAP, PlanBench and LLM-Modulo; self-consistency and best-of-$N$; outcome-reward RL; pass@$k$ and LLM judges; prompt injection, least privilege, sandboxing, approval gates and CaMeL; model-based RL.\par}
\end{frame}
