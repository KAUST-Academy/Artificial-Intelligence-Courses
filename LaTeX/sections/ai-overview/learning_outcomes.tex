\section{Learning Outcomes}
\begin{frame}{Learning Outcomes}
    \vspace{0.5em}
    \textit{By the end of this session, you will be able to:}

    \vspace{1em}
    \begin{enumerate}
        \setlength\itemsep{1.2em}

        \item Explain in your own words what AI, Machine Learning and Deep Learning are, and how they relate.

        \item Describe how a machine ``learns'' from examples instead of following hand-written rules.

        \item Recognise what today's AI can do with images and with language, including tools like ChatGPT.

        \item Name the main limits and risks of AI, and use AI tools responsibly.
    \end{enumerate}
\end{frame}
