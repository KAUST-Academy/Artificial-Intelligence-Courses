\begin{frame}{Key Takeaways}
    \begin{enumerate}
        \setlength\itemsep{0.9em}
        \item \textbf{AI} is about getting computers to do tasks that normally need human intelligence.
        \item \textbf{Machine Learning} is how most AI is built today: the computer learns from examples instead of following hand-written rules.
        \item \textbf{Deep Learning} uses large neural networks, and took off thanks to more data and faster computers.
        \item AI can now \textbf{see}, \textbf{read}, \textbf{write} and \textbf{create} --- chat assistants work by predicting the next word.
        \item AI is a powerful tool that still \textbf{makes mistakes} and \textbf{copies bias}. Check its work, and stay responsible for it.
    \end{enumerate}
\end{frame}
