\begin{frame}{How a Computer Sees an Image}
\begin{itemize}
    \item To a computer, an image is a grid of numbers. Each number says how bright one tiny square (a \textbf{pixel}) is.
    \item A colour image is three such grids: red, green and blue.
\end{itemize}

\centering

    \item \textbf{Classification}: what is in this picture?
